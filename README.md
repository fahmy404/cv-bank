# CV Bank

أداة سطر أوامر بسيطة لتجميع السير الذاتية في قاعدة بيانات SQLite تستطيع البحث فيها بسهولة.

## المتطلبات

- Python 3.10 أو أحدث.
- (اختياري) مكتبة [PyPDF2](https://pypi.org/project/PyPDF2/) لاستخراج النص من ملفات PDF.
- (اختياري) مكتبة [python-docx](https://pypi.org/project/python-docx/) لاستخراج النص من ملفات DOCX.

## البدء السريع

```bash
python -m cvbank.cli init
```

يعتمد الملف `cv_bank.db` على مجلد المشروع الحالي، وسيتم حفظ الملفات الأصلية داخل مجلد `cv_files/`.

### إضافة سير ذاتية

```bash
python -m cvbank.cli add "اسم المرشح" \
  --email example@mail.com \
  --phone 01000000000 \
  --job-title "Backend Developer" \
  --company "ACME" \
  --location "القاهرة" \
  --skills "Python, Django" \
  --file /path/to/cv.pdf
```

يمكن تكرار معامل `--skill` أكثر من مرة أو استخدام `--skills` بقائمة مفصولة بفواصل. إذا كان لديك ملف نصي جاهز يمكنك تمريره بواسطة `--text-source` ليُستخدم أثناء البحث.

### عرض السير الذاتية

```bash
python -m cvbank.cli list
```

يمكن التصفية باستخدام `--skill`, `--location`, `--company`, `--job-title`.

### البحث بالكلمات المفتاحية

```bash
python -m cvbank.cli search python القاهرة
```

يتم مطابقة الكلمات مع الاسم، البريد الإلكتروني، رقم الهاتف، المهارات، الوظيفة، الشركة، المكان، الملاحظات، والنص المستخرج.

### عرض سجل واحد بالتفصيل

```bash
python -m cvbank.cli show 1
```

### حذف سير ذاتية

```bash
python -m cvbank.cli delete 1
```

## تخزين الملفات

عند استخدام `--file` يتم نسخ الملف إلى مجلد التخزين مع اسم فريد. احرص على الاحتفاظ بنسخ احتياطية من المجلد بالإضافة إلى قاعدة البيانات.

## تخصيص المسارات

يمكن تمرير `--db` و `--storage` في أي أمر لتحديد موقع مختلف لقاعدة البيانات أو مجلد الملفات:

```bash
python -m cvbank.cli --db /path/to/data.db --storage /path/to/cv_storage add "اسم المرشح"
```

## ملاحظات

- في حالة عدم توفر مكتبات استخراج النص، يمكنك توفير نسخة نصية من السيرة الذاتية باستخدام `--text-source` لضمان ظهورها في نتائج البحث.
- استخدم أوامر `list` و `search` للحصول على قائمة المرشحين، مع إمكانية نسخ أسماء الملفات من الحقل `Stored file` لفتح النسخة الأصلية.
